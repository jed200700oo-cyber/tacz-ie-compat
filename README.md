# TaCZ - Immersive Engineering Compatibility - Comunidad Edition

A small Forge addon that connects Timeless and Classics Zero (TaCZ) with Immersive Engineering through an additional ammunition recipe.

## Supported versions

- Minecraft 1.18.2
- Minecraft Forge 40.x
- TaCZ Forge build for Minecraft 1.18.2 (`tac`)
- Immersive Engineering 8.4 or newer for Minecraft 1.18.2 (`immersiveengineering`)

The recipe targets TaCZ's 1.18.2 ammo item and NBT format, and Immersive Engineering's steel ingot and copper plate.

## In-game recipe

Combine one Immersive Engineering steel ingot, one copper plate, and one gunpowder in any arrangement to make 60 TaCZ 5.56x45 rounds.

## Build

Install JDK 17 and Gradle 7.5.x, then run:

```text
gradle build
```

The built mod jar is written to `build/libs/`. To test in a development client, install TaCZ and Immersive Engineering for Minecraft 1.18.2 in the Forge development run's `run/mods` directory, then run `gradle runClient`.
